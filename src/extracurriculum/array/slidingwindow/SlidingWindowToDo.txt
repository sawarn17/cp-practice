# 🧠 How to Actually Master Sliding Window

Don’t just solve—follow this **pattern recognition strategy**:

### 1. Identify Type Quickly

* Fixed size → move window directly
* Variable size → expand + shrink
* “At most K” → convert to “exactly K”

### 2. Memorize Core Templates

* Fixed window (sum/count)
* Variable window (set/map)
* AtMost(K) helper function

### 3. Practice Order (IMPORTANT)

* Easy → Medium (same pattern)
* Don’t jump randomly

# ⚡ Pro Tip (What Most People Miss)

Most medium problems reduce to:

```
exactly(k) = atMost(k) - atMost(k-1)
```

If you master this, half the list becomes easy.
