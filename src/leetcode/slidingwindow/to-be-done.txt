# 🧠 The Patterns You MUST Master

Don't just memorize the solutions. After completing the problems, you should be able to identify these patterns immediately.

### Pattern 1 — Fixed Window

```text
window size = K
```

Examples:

* 643
* 1456
* 1343
* 1052

---

### Pattern 2 — Longest Valid Window

```text
while window is invalid:
    left++

answer = max(answer, window)
```

Examples:

* 3
* 424
* 904
* 1004
* 1208

---

### Pattern 3 — Shortest Valid Window

```text
while window is valid:
    answer = min(answer, window)
    left++
```

Examples:

* **209**
* **76**

---

### Pattern 4 — Frequency Matching

```text
HashMap
    ↓
required frequency
    ↓
current frequency
    ↓
matched count
```

Examples:

* 567
* 438
* 76
* 30

---

### Pattern 5 — At Most K

```text
atMost(K)
```

Examples:

* 904
* 992
* 340
* 159

---

### Pattern 6 — Exactly K

```text
exactly(K)
=
atMost(K) - atMost(K - 1)
```

Examples:

* 992
* 1248
* similar "exactly K" counting problems

---

### Pattern 7 — Monotonic Deque

```text
Deque
 ↓
maintain maximum/minimum
 ↓
remove expired elements
```

Examples:

* **239**
* **1438**
* **862**

## 🚀 How I recommend you practice

For each problem, **don't immediately code**.

Use this process:

```text
1. Identify:
   Fixed Window OR Variable Window?

2. What makes the window INVALID?

3. What information must I maintain?
   sum?
   frequency?
   distinct count?
   matched count?
   max/min?

4. When do I move right?

5. When do I move left?

6. Is the question asking:
   maximum?
   minimum?
   count?

7. Can "exactly K" be converted to:
   atMost(K) - atMost(K-1)?
```

If you can answer those **before writing Java code**, you've genuinely learned sliding window rather than memorized solutions.

**Target:** Solve the 30-question set in the order above. Once you can solve them independently in **20–30 minutes each**, sliding window should be one of your strongest interview patterns.
