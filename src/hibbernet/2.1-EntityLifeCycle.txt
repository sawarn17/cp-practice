In Java Persistence API (JPA), the EntityManager is the primary interface used to interact with the database. 
It acts as a bridge between your Java objects and the relational database, managing the lifecycle of your entity instances (creating, reading, updating, and deleting).

Core Responsibilities : 
EntityManager governs a set of entities defined by a persistence unit and operates within an in-memory session known as the Persistence Context. 
Its main tasks include:
Persist: Saves a new entity instance to the database.
Find: Retrieves an entity by its primary key from the persistence context or database.
Merge: Re-attaches a detached entity back into the persistence context.
Remove: Deletes an entity from the database.
Query: Executes JPQL or native SQL queries to retrieve data
