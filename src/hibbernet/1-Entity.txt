Entity : 
Entities in JPA are nothing but POJOs representing data that can be persisted in the database. 
An entity represents a table stored in a database. Every instance of an entity represents a row in the table.


We must ensure that A entity class always have : NoArgsConstructor, Id
Because various JPA implementations will try sub classing our entity to provide their functionality, entity classes must not be declared final.

Id Annotation: 
Each JPA entity must have a primary key that uniquely identifies it. 
The @Id annotation defines the primary key. We can generate the identifiers in different ways, which are specified by the @GeneratedValue annotation.

We can choose from four id generation strategies with the strategy element. 
The value can be 

AUTO:  
TABLE: 
SEQUENCE:  
IDENTITY:
