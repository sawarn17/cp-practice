## 🚀 Git Workflow Quickstart

To keep development organized, always create feature branches from the raw baseline.

### How to Create a New Branch from Raw
Run the following commands in your terminal:

```bash
# Fetch the latest updates from remote
git fetch origin

# Switch to the raw branch
git checkout raw

# Pull the latest changes to stay updated
git pull origin raw

# Create and switch to your new feature branch
git checkout -b feature/your-branch-name
```
